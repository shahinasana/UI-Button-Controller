# UI Button Controller for ERPNext

A flexible and configurable solution to control button visibility in ERPNext based on Role, Company, and User.

# Features

- 🔹 Role-based button visibility  
- 🔹 Company-wise control  
- 🔹 User-specific restrictions  
- 🔹 Hide unnecessary buttons  
- 🔹 Improve UI clarity and user experience  


# Installation

bench get-app https://github.com/shahinasana/UI-Button-Controller.git
bench --site your-site-name install-app ui_button_control

# Configuration
1. Go to UI Button Controller Settings
2. Add rules for:
    -Role
    -Company
    -User
3. Select buttons to show or hide
4. Save and refresh

# Use Cases
- Restrict sensitive actions for specific roles
- Customize UI for different companies
- Simplify interface for end users
- Improve workflow control
